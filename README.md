# Portafolio de Tatiana Oseda

Portafolio personal de Tatiana Oseda, estudiante de Ingeniería de Sistemas en la Universidad Nacional del Centro del Perú. Presenta su experiencia, proyectos académicos, habilidades técnicas y actividades de investigación.

## Ver el portafolio en tu computadora

Abre el archivo `index.html` en un navegador.

## Publicarlo en GitHub Pages

1. Guarda y sube estos archivos a la rama `main` de este repositorio.
2. En GitHub, abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/(root)`, y guarda.
5. Espera a que GitHub Pages publique el sitio; la dirección aparecerá en esa misma sección.

Cuando edites el portafolio, guarda tus cambios, crea un commit y sincronízalo con GitHub para actualizar la página.
