## Ver el sitio

### En tu computadora

1. Descarga o clona este repositorio.
2. Abre `index.html` con tu navegador.

No necesitas instalar dependencias ni ejecutar un servidor: el sitio está hecho con HTML y CSS.

### En GitHub Pages

1. Sube `index.html`, `styles.css` y `README.md` a la rama `main`.
2. En GitHub, abre el repositorio y entra a **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama `main` y la carpeta `/(root)`; después, presiona **Save**.
5. Espera a que termine la publicación. GitHub mostrará el enlace del sitio en la sección **Pages**.

## Actualizar el portafolio

1. Edita `index.html` para cambiar textos, experiencia, proyectos o enlaces.
2. Edita `styles.css` para modificar colores, distribución y estilos visuales.
3. Guarda los archivos, crea un commit con un mensaje claro y sincroniza los cambios con GitHub.
4. Si GitHub Pages ya está activado, publicará la nueva versión automáticamente.
